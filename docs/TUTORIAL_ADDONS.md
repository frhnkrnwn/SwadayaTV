# Tutorial Addon SwadayaTV (Untuk Pemula)

## Apa itu Addon?
Addon adalah aplikasi kecil (APK tambahan) yang memberikan widget/fungsi ekstra untuk SwadayaTV. Contoh: cuaca, sholat, koin, scoreboard, dll. Addon **tidak wajib** — install hanya jika kamu mau fitur tersebut.

## Cara Install Addon

### Dari folder `addons/` (di repo)
1. Buka folder `addons/<nama-addon>/` di repo ini.
2. Build APK-nya (lihat README di folder addon) atau download APK pre-built jika tersedia.
3. Copy APK ke flashdisk/USB, lalu install di TV seperti biasa.

### Dari CleanYourTV
Beberapa addon berasal dari ekosistem CleanYourTV. Ikuti link di [addons/README.md](../addons/README.md) untuk detail.

## Cara Mengaktifkan Addon di TV

1. Install addon (APK) di TV.
2. Buka SwadayaTV → menu **Settings** (ikon roda gigi).
3. Pilih **"Tampilkan Kartu"** / **"Module Cards"**.
4. SwadayaTV akan mendeteksi addon yang terinstall. Aktifkan kartu yang diinginkan.
5. Kartu addon akan muncul di layar utama.

## Tips
- Addon hanya aktif jika kamu install APK-nya. Tidak install = tidak muncul.
- Untuk menghapus addon, uninstall APK seperti biasa dari TV.
- Lihat [addons/README.md](../addons/README.md) untuk daftar lengkap addon.
