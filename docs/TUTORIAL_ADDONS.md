# Tutorial Addon SwadayaTV (Untuk Pemula)

## Apa itu Addon?
Addon adalah aplikasi kecil (APK tambahan) yang memberikan widget/fungsi ekstra untuk SwadayaTV. Contoh: cuaca, salat, koin, scoreboard, dsb. Addon **tidak wajib** — pasang hanya jika Anda ingin fitur tersebut.

## Cara Memasang Addon

### Dari folder `addons/` (di repo)
1. Buka folder `addons/<nama-addon>/` di repo ini.
2. Build APK-nya (lihat README di folder addon) atau unduh APK siap pakai jika tersedia.
3. Salin APK ke flash drive/USB, lalu pasang di TV seperti biasa.

### Dari CleanYourTV
Beberapa addon berasal dari ekosistem CleanYourTV. Ikuti link di [addons/README.md](../addons/README.md) untuk detail.

## Cara Mengaktifkan Addon di TV

1. Pasang addon (APK) di TV.
2. Buka SwadayaTV → menu **Settings** (ikon roda gigi).
3. Pilih **"Tampilkan Kartu"** / **"Module Cards"**.
4. SwadayaTV akan mendeteksi addon yang terpasang. Aktifkan kartu yang diinginkan.
5. Kartu addon akan muncul di layar utama.

## Tips
- Addon hanya aktif jika Anda memasang APK-nya. Tidak dipasang = tidak muncul.
- Untuk menghapus addon, hapus APK seperti biasa dari TV.
- Lihat [addons/README.md](../addons/README.md) untuk daftar lengkap addon.
