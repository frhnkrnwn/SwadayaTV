Installing

The TV browser won’t download the file

Most TV browsers open the APK as text or refuse it. Two ways that always work:

  • Open the plain TV page and scan its QR code from the phone you are reading this on, then send the file to the TV (Downloader, a USB drive, or the phone’s own share sheet).
  • Install the Downloader app on the TV and type frhnkrnwn.github.io/SwadayaTV/tv into its address bar. The page is text only, so it loads even on a slow TV.

The phone app does the same job without typing anything: it downloads the launcher on the phone and installs it on the TV over Wi-Fi.

Play Protect says it can’t check the app

The launcher isn’t distributed through Google Play, so Play Protect has no record of it. On the warning sheet tap More details, then Install anyway. You do not need to turn Play Protect off.

The TV asks for permission to install

Android only lets a file manager, browser or Downloader install apps after you allow it: Settings → Apps → Special app access → Install unknown apps, pick the app you are installing from, and allow it. On some TVs the prompt appears by itself with a Settings button—use that.

“App not installed”

Almost always a signature mismatch: an older copy on the TV was signed with a different key (a debug build, or a build from before this site existed). Android refuses to replace it. Uninstall the old SwadayaTV first, then install the APK from this site. Settings and the dock are lost with that uninstall, so do it once and keep using this site’s APK afterwards—every build here is signed with the same release key and installs over the previous one.

Pressing Home still opens the old launcher

SwadayaTV is installed but not selected. On Google TV: Settings → System → Home screen (or Apps → Default apps → Home). On other Android TVs the entry is under Settings → Device preferences → Home screen. Pick SwadayaTV, then press Home twice.

Updating, and going back

How updates arrive

The launcher checks this site’s release/version.json once a day; a newer build appears in the bell and in Settings → About → Check for updates. It downloads the APK from this site, verifies its SHA-256, and hands it to Android. Your settings stay.

If the site is ever unreachable, the launcher falls back to the GitHub release, so updates keep working.

I want the previous build back

Android refuses to install an older version over a newer one, so this is a two-step: uninstall SwadayaTV, then install the previous build. Uninstalling clears the launcher’s settings, so treat it as a last resort and report what broke—a fix in the next build is usually quicker.

The full list of older builds is on Releases ↗.

Automatic updates with Obtainium

Prefer an app that updates it for you? Install Obtainium ↗, add https://github.com/frhnkrnwn/SwadayaTV, and it follows this repository’s releases. The APKs are signed with the same key, so Obtainium’s updates install over the launcher just like the built-in updater’s.

Checking the file

What the SHA-256 means

Every build has a fingerprint: the SHA-256 of the exact APK behind the button on this site. The live value is in release/version.json and next to each build in What’s new.

On a computer: sha256sum tvhome-latest.apk (Linux) or shasum -a 256 tvhome-latest.apk (macOS). On a phone, any checksum app shows the same string. If it doesn’t match, the download was altered or cut short—delete it and download again.

Does installing this need USB debugging or a computer?

No. USB debugging is only for a few extras inside the app (see the note in Install). The launcher, Live TV, wallpapers, weather, prayer times, the phone remote and updates work without it.

Swadaya App on the phone

The app can’t find the TV
  • Phone and TV must be on the same Wi-Fi; guest networks and “AP isolation” block it.
  • On the TV, turn on USB debugging and Network debugging (Developer options). The TV asks for permission the first time—choose Always allow.
  • Type the TV’s IP address exactly as shown in Settings → Network on the TV.
  • Turn debugging back off when you are done; nothing in the app needs it afterwards.
Can the app install the launcher on the TV for me?

Yes. That is the shortest path: install Swadaya App on the phone, connect it to the TV, and use its install button. The app downloads the same APK this site publishes and pushes it to the TV; you never type an address on the TV.

Something not covered here? Open an issue ↗ with the TV model, the Android version from Settings → About, and what you saw.
