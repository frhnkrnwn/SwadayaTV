# Swadaya Addon: Koin

Status: **placeholder**. Fitur kurs koin SwadayaTV ini belum dibuat — folder ini hanya menampung rencana dan acuan untuk nanti.

Rencana datanya dari **Frankfurter** (API kurs tukar tanpa API key): menampilkan nilai tukar yang masuk akal untuk kartu kecil di Home, misalnya USD/IDR, EUR/IDR, atau pasang mata uang favorit Anda. Label kartu: `Koin`, caption: `Kurs tukar`.

Addon ini akan **aktif-mati mandiri**: mengambil kurs hanya saat layarnya terbuka, tidak ada layanan di latar belakang. Jadi tidak bentrok dengan launcher SwadayaTV — cukup pasang APK-nya, setujui "Show card" sekali, dan kartu Koin muncul di Home.
